# 🚀 GetPlaced

### AI-Powered Placement & Career Readiness Platform

🌐 **Live Demo:** [https://getplaced.siqht.in](https://getplaced.siqht.in)

GetPlaced is an AI-powered placement and career development platform that helps students understand **how ready they are for a specific company and role**, identify their biggest skill gaps, and receive a personalized action plan to improve their chances of getting hired.

Instead of simply tracking activities such as LeetCode problems solved, GitHub repositories, or resume scores, GetPlaced connects these signals with the requirements of the **target company + role** and turns them into actionable placement intelligence.

---

# 🎯 The Problem

Placement preparation is fragmented across multiple platforms.

Students use:

- **LeetCode** → DSA practice
- **GitHub** → Projects and coding activity
- **YouTube** → Learning resources
- **Resume tools** → ATS optimization
- **Interview platforms** → Technical and HR preparation
- **Job portals** → Job discovery
- **LinkedIn** → Professional profile

But these platforms operate independently.

A student may know:

> *"I have solved 300 LeetCode problems."*

But still not know:

> **"Am I actually ready for the job I want?"**

GetPlaced brings these signals together and answers three important questions:

1. **Where am I?**
2. **What's holding me back?**
3. **What should I do next?**

---

# 💡 Our Solution

GetPlaced creates a personalized placement profile using information from:

- GitHub
- LeetCode
- Resume
- Skills
- Projects
- Education
- Achievements
- Self-assessment
- Target company
- Target role

The platform analyzes this information against the requirements of the selected role and generates:

```text
Profile
   ↓
Evidence
   ↓
Role Requirements
   ↓
Placement Readiness
   ↓
Skill Gaps
   ↓
Prioritized Actions
   ↓
Progress
```

The goal is not simply to tell students what they have done.  
**The goal is to tell them what they should do next.**

# ⭐ Key Features

### 🤖 AI-Powered Onboarding
Instead of filling out a long form, users interact with an AI onboarding assistant.

The assistant collects:
- Name, College, Degree, Graduation year
- Target company & Target role
- GitHub, LeetCode, LinkedIn profiles & Resume
- Skills, Experience & Self-assessed skill levels
- Career goals & Preparation timeline

The collected information is used to build the student's career profile.

---

### 📊 Placement Readiness Score
GetPlaced generates a role-specific placement readiness score.

```text
MICROSOFT · SDE

PLACEMENT READINESS
74 / 100

TARGET: 90

Breakdown:
DSA           68 / 85
Projects      75 / 85
Resume        84 / 90
Interview     64 / 80
```

This gives students a measurable understanding of where they currently stand.

---

### 🔎 Skill Gap Analysis
GetPlaced identifies the difference between the user's current skill level and the level required for their target role.

```text
React
Your Level       6 / 10
Required         8 / 10
Gap              2
```

Skill estimation considers multiple sources of evidence:
- GitHub activity
- Projects & Deployments
- Resume & LinkedIn
- LeetCode activity
- Self-assessment

The system avoids blindly trusting a single source.

---

### 💻 Coding & DSA
The Coding workspace helps students improve their DSA preparation with:
- Topic-wise analysis & DSA analytics
- LeetCode practice & problem recommendations
- Practice sheets (Striver-style SDE sheets)
- Difficulty-based & topic-based practice
- Integrated YouTube learning resources

```text
Example:
Graphs — 32 Problems
Easy: 8  |  Medium: 17  |  Hard: 7

[ Practice on LeetCode ]
```

---

### 🚀 Development & Project Analysis
GetPlaced evaluates technical project profiles across multiple dimensions:
- Technology stack
- Complexity & Architecture
- Relevance to target role
- README quality & Documentation
- Deployment & Live URLs
- Impact & Scale

```text
UniFetch
Technology       9 / 10
Complexity       8 / 10
Relevance        9 / 10
README           7 / 10
Deployment      10 / 10
Impact            6 / 10
------------------------
Overall          82 / 100
```

Identifies technology gaps based on the target role (e.g., Spring Boot: Your Level `4/10` vs Required `7/10` → Gap `3`).

---

### 📄 AI Resume Builder
Create and refine resumes using information already available in the profile:
- Education, Skills, and Projects
- GitHub stats, LeetCode achievements, and Experience
- Reduces repetitive resume creation while keeping content aligned with reality.

---

### 🎯 ATS Resume Analysis & Improvement
Analyzes resumes against selected roles with granular ATS scoring:

```text
ATS SCORE: 84 / 100
Keywords: 88% | Structure: 92% | Skills: 85% | Projects: 78% | Formatting: 90%
```

Identifies actionable fixes:
- ❌ Add missing React keywords
- ❌ Add measurable project impact (Google XYZ formula)
- ❌ Improve project descriptions with action verbs
- ❌ Add deployment links

Users can review suggested diffs and apply fixes with 1-click.

### 🎯 Career Intelligence
- **🎯 Can I Apply?** — Checks eligibility and readiness for target job openings.
- **🧭 Which Role Fits Me?** — Matches current skills and projects to best-fitting roles.
- **⚡ Fastest Path** — Pinpoints the top 3-4 high-ROI tasks to achieve maximum readiness jump.
- **🧪 What If?** — Simulates how improving a specific skill changes projected readiness.
- **🧠 Don't Work On This Yet** — Flags low-priority distractions to keep focus on high-impact gaps.

# 🧩 Backend Architecture

GetPlaced uses separate backend responsibilities:

### Node.js Backend (`backend-Node`)
Responsible for application-level functionality:
- Authentication & User Management (JWT)
- Profile state & MongoDB interaction
- Application APIs & LeetCode/GitHub proxy caching

### Python AI Backend (`backend-Py`)
Responsible for AI, document processing, and intelligence features:
- Comprehensive ATS Resume Analysis & Bullet Optimization
- Mock Interview Evaluation & Communication Scoring
- Live AI Code Assistance & Guidance Streaming
- Company Intelligence & Role Gap Scoring

# ⚙️ Environment Variables

Copy `.env.example` to create your `.env` files:
```bash
cp .env.example .env
```

### Key Configuration

| Variable | Purpose |
|---|---|
| `GOOGLE_API_KEY` | Google Gemini API key (powers all AI features) |
| `RAPIDAPI_KEY` | RapidAPI JSearch key for live job listings |
| `MONGO_URI` | MongoDB connection URI |
| `JWT_SECRET` | Secret token for JWT session authentication |
| `VITE_NODE_API_URL` | Node.js backend URL (default: `http://localhost:3000`) |
| `VITE_PY_API_URL` | Python AI backend URL (default: `http://localhost:8000`) |

> 🔒 **Security Note**: Never commit `.env` files, API keys, database credentials, or secrets to the repository.

# 🚀 Quick Start

### Option A: Docker Compose (Recommended)

```bash
# 1. Clone repository
git clone https://github.com/shi-ivam/getplaced.git
cd getplaced

# 2. Setup environment variables
cp .env.example .env

# 3. Start services
docker compose up --build -d
```

- **Frontend App**: `http://localhost` (Port 80)
- **Node.js API**: `http://localhost:3000`
- **Python FastAPI**: `http://localhost:8000` (`http://localhost:8000/docs`)

---

### Option B: Local Development

#### 1. Frontend
```bash
cd frontend
npm install
npm run dev
```

#### 2. Node.js Backend
```bash
cd backend-Node
npm install
npm start
```

#### 3. Python AI Backend
```bash
cd backend-Py
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --port 8000 --reload
```
